# Detecção de Rostos em Imagens com OpenCV

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Projeto desenvolvido em Python utilizando a biblioteca OpenCV para detectar rostos em imagens estáticas, destacando-os com retângulos.

---
## 📚 Aprendizados
- Utilização da biblioteca OpenCV para visão computacional
- Leitura e processamento de imagens
- Conversão de imagens para tons de cinza
- Detecção de rostos utilizando o classificador Haar Cascade
- Utilização de estruturas de repetição para destacar os rostos identificados
- Configuração e execução do código no Visual Studio Code

## ⚙️ Funcionalidades
- Carregamento de imagens armazenadas no computador
- Detecção automática de rostos presentes na imagem
- Identificação visual dos rostos por meio de retângulos
- Exibição da imagem processada em uma janela

## 🛠️ Stack
Tecnologias e ferramentas utilizadas:
- Python
- OpenCV (cv2)
- Haar Cascade
- Visual Studio Code

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/BiaHashi/detectando_rostos_em_imagens
```

2. Abra o arquivo ".py" e execute-o no VS Code.
